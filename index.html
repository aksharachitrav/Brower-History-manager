Viva Voce Quick Reference

Concise answers to common college examination questions.

❓ Why Doubly Linked List for Browser Navigation?

Answer: Browsers require bidirectional movement (Back & Forward). A Doubly Linked List has two pointers: prev (for Back) and next (for Forward). Moving between pages takes O(1) constant time without shifting elements.

❓ What happens when you visit a new URL after clicking Back?

Answer: Any forward history ahead of current is discarded/orphaned (current.next = null), and the new node is linked. This matches real browser behavior!

❓ Why use an Array for History Log?

Answer: An Array maintains total chronological records with fast index-based access and sequential iteration for features like search, sorting, filtering, and export.

❓ How does Search History work?

Answer: It performs a Linear Search over the history Array with time complexity O(N), comparing the search string against each entry's URL and title.
